# Security Policy — Riftop

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Riftop, please report it privately:

- **Email:** Send security advisories to `security@riftop.org` or open a private security advisory on GitHub.
- **Response Time:** We aim to acknowledge receipt of security reports within 48 hours and provide a resolution or patch timeline within 7 days.

Please do **not** open public GitHub issues for unresolved security vulnerabilities.
